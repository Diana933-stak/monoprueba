# Gestor de Historias de Usuario (PHP MVC)

## Requisitos
- XAMPP (Apache + MySQL)
- PHP 8+

## Instalación rápida
1. Copia la carpeta `gestor-historias` a `htdocs`.
2. Importa `config/schema.sql` en phpMyAdmin.
3. Abre `http://localhost/gestor-historias/public/index.php`.

## Estructura
- `config/`: conexión PDO y SQL base.
- `models/`, `controllers/`, `views/`: MVC.
- `public/`: front controller, css y js.
